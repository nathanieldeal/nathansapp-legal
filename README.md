# nathansapp-legal

Public legal pages for NathansApp, served with GitHub Pages.

- Privacy policy: https://nathanieldeal.github.io/nathansapp-legal/privacy/

Update the effective date whenever the policy changes.

The Apple Health section must describe what the app in review actually does
(Apple checks the policy against the binary, Guideline 5.1.3). As of the
2026-09-19 revision, daily Apple Health totals **can** leave the device, with
consent, and can be shared with a named caregiver, so the section covers
reading, saving, keeping totals in the account, sharing, and stopping. Do not
weaken it back to "on your device only".

The policy must also not describe features a user cannot get yet: it describes
in-app account deletion and in-app caregiver linking, both of which ship in the
app. Password reset does not exist yet, so the auth email provider (Resend) is
deliberately not named; add it when password reset ships.
